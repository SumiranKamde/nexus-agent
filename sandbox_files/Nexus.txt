Project Name: Nexus
Description: Nexus is a personal productivity assistant designed to help users manage tasks, files, and information efficiently.
Capabilities:
- File management (create, read, edit, search, list)
- To-do list management (add, complete, list, audit, undo)
- Web searching and content extraction
- Memory management (remember, list, forget)
- WhatsApp integration for notifications and file sharing
- Time and date tracking
- Proactive notifications
Goal: To provide a seamless, personalized assistant experience for users like Sumiran.
